# TERENSAI — Ритм парения

Android-приложение для ведения банных программ.

Первая версия 0.1.0: офлайн часы, хронометр процедур, этапы и локальный журнал.

Сборка тестового APK выполняется GitHub Actions. Сборка использует исходный архив `android-sources.tar.xz` из этого репозитория; он содержит проект Android Studio и встроенный веб-интерфейс. При публикации новой версии архив необходимо обновить.

Приложение не является медицинским средством и не предназначено для автоматического ограничения времени нахождения в парной. Временные ориентиры настраиваются мастером.
