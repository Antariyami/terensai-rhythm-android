# ПАРИТМ — Ритм банного мастерства

Авторское Android-приложение для планирования и проведения банных программ: таймеры, единая шкала «план / факт», архив сессий, мягкие напоминания, будущий редактор собственных ритуалов.

**Текущий стабильный прототип:** `0.1.0-test` — Java Activity, программа «Танысу», секундомер и локальное сохранение активного состояния. **Версия 0.2 пока проектируется.** Не путайте визуальные концепты и GitHub Issues с реализованными функциями.

### Сборка отладочного APK

GitHub Actions workflow `Build TERENSAI Android debug APK` запускается при изменениях кода и по запросу через `Actions → Run workflow`. Результат находится в артефактах соответствующей сборки. Автоматическая **публикация** APK в Releases отключена, чтобы не заменять старый пакет с другим отладочным сертификатом.

Для локальной сборки нужны Android SDK 35, Build Tools 35.0.0, JDK 17, Gradle 8.9 (последний может быть установлен через Android Studio):

```bash
gradle :app:assembleDebug
```

## Архитектура — направление v0.2

Kotlin + Jetpack Compose / ViewModel + StateFlow / Room / DataStore, event-driven timeline, чистая бизнес-логика через domain contracts. **Миграция постепенная, текущая Java версия остаётся контрольной до регрессионных испытаний.**

## Важные ограничения

- Таймеры являются организационными подсказками и **не задают безопасную длительность тепловой нагрузки**.
- Предустановленные этапы, не подтверждённые методологически, обозначаются как черновики.
- Release keystore, пароли, гостевые личные данные не коммитить в публичный репозиторий.
- Бренд «ПАРИТМ» — рабочее название до проверки права использования и регистрации.
