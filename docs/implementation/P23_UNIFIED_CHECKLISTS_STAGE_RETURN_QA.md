## Проверки
CI запускает JVM tests + сборку Android APK + **компиляцию** APK инструментальных тестов; это НЕ физическое исполнение Android instrumentation tests. Только владелец на Xiaomi подтверждает приёмку.
Известные ограничения: P2.1 блокирует возврат уже учтённого S13 этапа; P2.2 не содержит утверждённых списков для сдачи смены/подготовки программы; PM1 пока не размножает блок по нескольким парным; шаблон JSON export — не экспорт результата конкретной смены.
