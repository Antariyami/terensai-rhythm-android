## Реализованное ядро
- Room v8, явная additive `MIGRATION_7_8`: `checklist_templates` и `checklist_runs`; нет изменения старых таблиц и нет destructive fallback.
- Каждый запуск содержит **полный JSON snapshot** версии шаблона, ответы, заметки, решение и времена. Редактор не переписывает исторические run.
- Исходные шаблоны приёмки PM1: **7 страниц, 61 пункт**; сбор личной сумки: **4 блока, 14 предметов**. «Сдача смены» и «Подготовка программы» пока не заполнены — перечни владелец предоставит отдельно.
- «Моя смена → Чек-листы»: проходить по страницам, отмечать и сохранять пункты, блоковые заметки, возвращаться после закрытия.
- «Настройки → Шаблоны чек-листов»: изменять названия/количества, переставлять блоки и пункты, добавлять/удалять их; версия шаблона обновляется. Исторический run не изменяется.
- Экспорт JSON через системный Storage Access Framework; импорт с **предпросмотром**, проверкой schemaVersion и копированием под новым templateId, без перезаписи предыдущего шаблона.
- В PM1 три взаимоисключающих финальных статуса; для CRITICAL обязательное текстовое описание проблемы.
- В сборе сумки галочки сбрасываются **только при явном запуске новой проверки**, а не при сворачивании. Ориентир времени 10+15+15 минут показан в исходном ТЗ; фоновые напоминания в данной итерации ещё не реализованы.

## Непокрытые требования для следующих небольших доработок
- Список подзон парных PM1 в одном run (сейчас общий блок «Парные и печи»; в заметках можно указать парную; отдельные повторяемые подзоны ещё не реализованы).
- История всех завершённых прохождений и экспорт **результата конкретной приёмки** (в Room есть, UI пока фокусируется на текущем run и экспорте шаблона).
- Настройка заголовка самого шаблона; редактор поддерживает блоки и пункты. Напоминание за 30 минут до выхода тоже отдельно.
- Финальные шаблоны сдачи смены и подготовки программы после передачи исходных перечней.
