# N1.1 · испытание навигации и Telegram-архива на Xiaomi 13T Pro

## Что изменилось по запросу пользователя
- Постоянная панель с **шестью разделами** на экранах Главная, Программы, Моя смена, Отчёты, Аналитика, Настройки. Подсветка активной вкладки. Кнопки доступны при просмотре S13 и программ. В фокусе полноэкранная компоновка ещё подлежит визуальной переработке B3.2.
- Кнопка «Мастера · личный профиль и справочник» **удалена из «Моя смена»**, доступна через Настройки. «Моё участие» осталось в смене.
- Пять сьютов: 1 Көркемдік, 2 Өркендеу, 3 Байлық, 4 Амандық, 5 Сәттілік. **Только точно совпадающий старый исходный список** обновляется автоматически. Любой частично изменённый пользователем список не переписывается; исторические snapshots в базе не изменяются.
- Telegram S13: «Сегодня», «Этот месяц», «Последние 6 месяцев», «Всё время». Период независим от фильтра дня/PM1 в основном журнале. Незавершённые работы не учитываются. Короткие сообщения отправляются текстом, длинные — .txt, архив за всё время — .html (UTF-8). Отправка только после действия пользователя через системный chooser, без API Telegram или подключения к Интернету. Подробный WhatsApp-отчёт сохраняется.

## Чек-лист на физическом телефоне
1. Из всех шести разделов можно переходить напрямую; выбранный раздел выделен.
2. Из «Моей смены» открыть текущую программу, вернуться, открыть S13, переключиться в Настройки — панель остаётся доступной.
3. В «Моей смене» **нет** кнопки справочника мастеров; «Моё участие» осталось. В «Настройках» открыть профили Андрей и Олжас и вернуться обратно.
4. Проверить новый порядок сьютов 1–5 в Настройках и при выборе сьюта для программы. Отредактировать тестовое название, перезапустить, убедиться в сохранении без перезаписи.
5. Создать/завершить индивидуальное или коллективное парение и подтвердить в S13; выполнить отчёт «Сегодня», проверить дату, PM1, сьют, количество.
6. Для «Этот месяц» и «Последние 6 месяцев» убедиться, что события одного дня не дублируются, а другие дни включаются; проверить итоговое количество.
7. Для «Всё время» отправить HTML-файл в Telegram/системный chooser, открыть файл, проверить кириллицу и структуру. Если месячный текст слишком длинный, он станет TXT-файлом.
8. Вернуться в WhatsApp-отчёт: формат сохранён.
9. Полностью закрыть приложение и заново открыть: сьюты, личный журнал и таймеры сохраняются, панели навигации не исчезают.

## Известные ограничения
- APK имеет **новый идентификатор** `kz.paritm.n11.preview`; прежние данные N1 QA2 автоматически не переезжают. **Старые APK не удалять.** Многопериодные отчёты проверяются после создания нескольких тестовых записей в N1.1.
- Отчёт за всё время содержит только записи **этой локальной базы и выбранного личного профиля**, а не других установок/телефонов.
- Для внешних процедур без visitId каждая работа остаётся отдельным блоком, иначе есть риск смешения бронирований. Исполняемые маршруты LIGHT/GRAND/PREMIUM/SUPREME и полная аналитика — ещё будущие этапы.
- Android instrumentation APK компилируется в CI, но автоматический CI без эмулятора не заменяет ручную приёмку.

## Протокол
Чек-лист пользователь отмечает по пунктам, непроверенное — не ошибка, комментарии могут отправляться до окончания всей проверки. Версия принимается только после подтверждения пользователя.
