# ПАРИТМ · B1 — утверждённый UI, QA preview

**Дата:** 13.10.2026. **Статус:** реализация B1 на отдельной ветке, unit tests и assembleDebug успешны. APK опубликован как [предрелиз](https://github.com/Antariyami/terensai-rhythm-android/releases/tag/v0.2.0-b1-approved-preview-2). Не объединять автоматически с main до визуальной приёмки владельцем на Xiaomi 13T Pro.

## Реально реализовано
- Jetpack Compose: приветствие S01 и каталог программ S02 с работающими кнопками, информационным диалогом и возвратом Android Back;
- цвета Design System 1.0, повторно используемые `ParitmTheme` и `ParitmPrimaryButton`;
- утверждённая художественная эмблема ПАРИТМ включена как оптимизированный растровый WebP (в QA первоначально уменьшенный до 128×128; для **финального** B1 потребуется экспорт высокого разрешения из 1024×1024 исходника);
- адаптивный значок + монохромный Android-вариант;
- типизированная библиотека 9 программ; 180/240/240/300/300 мин только там, где нормы подтверждены, остальные «Время уточняется»;
- новая тестовая установка изолирована от 0.1 и прошлого B1 через `applicationId=kz.paritm.preview.approved`;
- существующий Java экран парения «Танысу» доступен как **пилотный таймер**, а не новый экран plan/fact;
- JUnit tests для программы, длительностей, уникальных идентификаторов; прежние доменные тесты 0.2-A не отключались.

## Что пока НЕ реализовано и что проверить
- B2: вход в реальную сессию, Room-backed UI, план/факт/прогноз и миграция данных;
- B3: портретный/ландшафтный фокус;
- C/D: архив, WhatsApp, настройки, звуки, уведомления;
- 0.3/0.4: конструктор, аналитика;
- отдельные художественные фоны в исходниках не вырезаны из макетов — пока используем программные градиенты. Следовательно, сходство с фото-референсами **не пиксельное**;
- иконка в тестовом APK сжата до 128×128 WebP, она подходит для проверки композиции, но высокодетальный коммерческий launcher asset ещё не оформлен;
- APK подписан **временным debug-ключом** GitHub Actions; будущие отладочные APK могут иметь другой сертификат, поэтому не обещать обновление поверх этой версии;
- аппаратный QA Xiaomi 13T Pro, ориентация, TalkBack, fontScale, реальная читаемость и сохранение после повторного запуска — ещё ожидают пользователя.

## Приёмка B1
Проверить: установка параллельно старой программе; фирменная иконка; приветствие и CTA; scroll каталога; раскрытие каждой карточки; черновик не запускается; «Танысу» открывает прежний таймер; Android Back; отсутствие обрезки шрифтов в HyperOS.

После отзывов и финального экспорта высокой детализации иконки — итоговый B1 PR review, только затем переход к B2.
