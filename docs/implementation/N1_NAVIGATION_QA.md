# ПАРИТМ N1 — Приёмка навигации на Xiaomi 13T Pro

Основа: технически принятая B3.1, принятый журнал B2.4.3a hotfix, отдельный applicationId `kz.paritm.n1.preview`.

## Что проверять
1. С первого экрана видны все 6 разделов: Главная, Программы, Моя смена, Отчёты, Аналитика, Настройки. Плашки навигации 2×3; не требуется боковая прокрутка или угадывание невидимых разделов.
2. «Программы»: прежний утверждённый каталог открывается без изменения; только «Танысу» имеет исполняемый маршрут. SELECT и остальные остаются предпросмотрами, пока регламенты не подтверждены.
3. «Моя смена»: открываются 5 слотов программ, список «Мои процедуры», «Мастера» и журнал. Личные RUNNING таймеры не размножаются.
4. «Отчёты»: открывается S13 напрямую из главного меню, без необходимости начинать программу. В S13 присутствует журнал этапов программы, подтверждение личного парения, экспорт Telegram/WhatsApp.
5. «Аналитика»: честная пометка «в разработке», есть рабочая кнопка перехода в существующие отчёты. Не показывать числа-заглушки.
6. «Настройки»: реальный SuitePicker, «Изменить» с добавлением/переименованием сьюта и сохранением после возврата/перезапуска, переход в справочник мастеров. Звуки и напоминания пока подписаны как будущие функции.
7. При возвращении из дочерних Activity меню остаётся открытым, в принятом B3.1 можно зайти в ФОКУС и вернуться.
8. Данные старых отдельных QA пакетов не перенесены: создавать тестовые процедуры заново. Не удалять предыдущие установленные версии до экспорта.
9. Исторический snapshot старого сьюта в завершённых программах не переписывается после редактирования справочника.

## Принципиальная неопределённость
Пользователь противоречиво продиктовал №3, 4, 5:
- Уверенно №1 Көркемдік, №2 Өркендеу.
- Слова о Байлық, Амандық, Сәттілік требуют повторного подтверждения.
До подтверждения дефолтный набор и сохранённые названия **не перенумеровывать автоматически**. Это отдельный issue #31.
