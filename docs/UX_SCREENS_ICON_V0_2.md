## Дизайн-токены

- Основной фон `#15110F`, поверхность `#281E1A`, тёплый акцент `#F2A047`, бронза `#C69B66`, текст `#F6F1E8`, успех `#95AC8C`, предупреждение `#D27658`.
- Основная кнопка 60–72dp высотой, все зоны касания не меньше 48×48dp. TalkBack, увеличение шрифта, контраст, поясняющий текст состояния обязательны.
- Первичное устройство — Xiaomi 13T Pro; Compose использует реальные dp и safe-area, а не фиксированные пиксели дисплея. Офлайн — базовое требование.

## Основные переходы

S01 → S02 → S03 → S04 ↔ S05. S04 открывает QuickActionsSheet: пауза/пропуск/добавление/продление/заметка. Каталог S02 ведёт к S09 (мои программы); S06 → S07; S08 ведёт к отфильтрованному S06. S10 доступен из верхних настроек. Активная сессия восстанавливается без запуска второго таймера.

## Программные контракты

1. `ViewModel` → `domain` → `Repository` → `Room`; экрану запрещено самому вести бизнес-время через отдельный локальный секундомер.
2. Сессия получает immutable snapshot выбранного ProgramTemplate, факт фиксируется событиями с уникальным ID, план не двигается от отставания; прогноз вычисляется отдельно.
3. Параллельные задачи мастера и отдых гостей — разные дорожки; общую длительность программы не складывать повторно.
4. Archive + report сохраняются офлайн, WhatsApp только через Android Sharesheet по действию пользователя, без автоматической передачи персональных данных гостей.
5. Проверка миграции 0.1 SharedPreferences в Room обязательна до переключения UI; сохранить исходный журнал и не выдумывать временные метки.
6. Системные звуковые напоминания проходят отдельную проверку разрешений Android/HyperOS и энергосбережения; не обещать гарантированную работу без разрешений.

## Иконка: три исполнения + размеры

Референс — бронзовый круг часов, завиток пара, перекрещённые дубовые листья, тёмный фон; **без надписей внутри иконки**.
- **01 Full color:** исходный квадрат 1024×1024 PNG + 512×512 PNG.
- **02 Simplified vector:** исходный SVG, масштабируемые PNG 192/144/96/72/48.
- **03 Android Adaptive:** прозрачный foreground 432×432, задник `#18110F`, monochrome 432×432 (для themed icons), `mipmap-anydpi-v26/ic_launcher.xml`.
- Безопасная зона adaptive icon — центральные 66×66dp внутри холста 108×108dp. Проверить лаунчеры с круглыми и квадратными масками.

## Критерии готовности каждой итерации

- Спецификация и экранные состояния (пусто/ошибка/активно) утверждены.
- Нет второй реализации domain времени в Compose.
- Unit/UI тесты, сохранение/восстановление, миграция и офлайн проверены.
- На Xiaomi проверены кнопки, масштаб шрифта, блокировка, Android navigation.
- APK подписан стабильным ключом для релизов; **debug builds не перепубликовать вместо постоянного release**.

**B1** S01, S02 и design system → **B2** S03, S04 → **B3** S05 → **C** S06, S07 → **D** S10 и напоминания → **0.3** S09 → **0.4** S08. Иконка готовится параллельно B1.
