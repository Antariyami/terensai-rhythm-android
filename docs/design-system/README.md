# UI-kit ПАРИТМ 1.0 — документация

1. [DESIGN_SYSTEM_1.0.md](DESIGN_SYSTEM_1.0.md) — источник истины для палитры, типографики, размеров, иконок, компонентов, состояний и математической логики план/факт.
2. [tokens.json](tokens.json) — машиночитаемые значения для дальнейшего подключения в Kotlin/Compose.

**Статус:** в этом PR только документы. GitHub Android-экраны и подписанные APK не меняются. Реализацию делаем следующими отдельными PR с проверками и утверждением дизайна.

**Вне GitHub:** отдельный скачиваемый пакет содержит Word-документ и офлайн-витрину компонентов (`ui-kit.html`) с визуальным референсом премиальной иконки. Изображения не считаются готовыми Compose-компонентами.

### При внедрении
- Для Android используются dp/sp, системные insets и accessibility labels.
- Совпадение цветов не означает достаточную контрастность: проверьте каждый текст на реальной фотографии и Xiaomi.
- В режиме S05 астрономическое время вверху, крупное, полупрозрачное; в фокусе основное смещение — **отклонение активной процедуры**, глобальный сдвиг — на S04.
- Пример: `12:15 / 15:00` означает **осталось 02:45**; лишь `17:45 / 15:00` даёт **превышение +02:45**.
- Ретроспективное редактирование шаблона не должно изменять snapshot уже начатой сессии.
