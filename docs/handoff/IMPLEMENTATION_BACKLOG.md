## Ассеты: что готово лишь как визуальный ориентир

| Группа | Требуемый deliverable | Статус |
|---|---|---|
| Адаптивная иконка ПАРИТМ | 1024/512 исходник, 432 foreground, background, mono | эмблема утверждена как изображение; Android ready-export предстоит проверить |
| Фоны S01/S02/S04/S05 | portrait+landscape clean WEBP без текста и кнопок | художественные reference only |
| Обложки программ | оптимизированные кадры, отдельные от карточек | референсы, для MVP опционально |
| Монограммы Т,L,G,P,S,Se,Sp,O,TL | текстовые Compose медальоны 40–44dp | алгоритм утверждён |
| Пиктограммы процедур | 6 SVG/vector: парение, отдых, подготовка, SPA, чай, другое | нужно создать |
| Шкалы, буллеты, цифры | Compose Canvas / UI primitives | не растровый ресурс |
| Звуки | 4 лицензированных audio: Колокольчик, Чаша, Лес, Поток | отсутствуют, создать/проверить права |
| Корпоративная библиотека | отдельные текстовые/графические assets | не вшивать в продукт без согласования прав |

Семантическая палитра — [Design System](../design-system/DESIGN_SYSTEM_1.0.md): Plan `#F2A047`, Fact `#45D6B1`, Overrun `#F58A35`. Не путать наличие референса с разрешением на коммерческое использование или наличием Android asset.

## Acceptance (минимум)
1. Выбрать программу и стартовать дважды быстрым нажатием → создана **одна** сессия.
2. Действие «К сессии»/Android Back из S05 не ставит stage на паузу и не сбрасывает timer.
3. 12:15/15:00 → осталось 02:45, **не** +02:45; 17:45/15:00 → оранжевое +02:45.
4. Начало на 6 мин позже, stage E=P → «старт +6», а не overrun.
5. Guest rest 25 + одновременные master tasks 7+5+13 → timeline 25 мин, а не 50.
6. В архиве монограммы соответствуют программе и есть текст названия.
7. Недостоверный шаблон Select/Orda/… не запускается как подтверждённый.
8. WhatsApp через Android Sharesheet с корректной кириллицей и без персональных данных по умолчанию.
9. Уведомления denied → честное состояние, системное разрешение отдельно от UI toggle.
10. QA реальный Xiaomi 13T Pro: экран блокирован/поворот/крупный шрифт/нет интернета/перезапуск/восстановление из backup.
11. Две последовательные релизные сборки подписаны **одним** release-key; upgrade сохраняет данные.

## Инженерная готовность

Каждая функция принимается только после: реализована, реальные данные (не макет), тесты зелёные, review, ручной прогон Android/HyperOS, подтверждение владельцем. Эскиз в Figma/PNG и debug APK **не** означает завершения функции. Общие требования в [аудите UX](../ux-audit/STAGE2_CROSS_SCREEN_AUDIT.md).
